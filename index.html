"Screen notifications" use your browser's real notification system — once enabled, the morning briefing and posting alerts pop up as OS-level banners, not just inside the tab. This works well on desktop Chrome/Edge/Firefox and on Android Chrome. iPhone Safari only supports this if you add this page to your Home Screen as an app (Share → Add to Home Screen) — a regular Safari tab can't show them due to Apple's restrictions. Either way, this tab needs to still be open (it can be in the background) for the timer to fire — fully closing the browser stops it. For reminders that work even fully closed, use your phone's built-in Alarm app for the 10pm nudge, and Google Calendar recurring events for exact posting slots — ask me and I'll generate an importable calendar file too.
